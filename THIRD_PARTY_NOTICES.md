# THIRD_PARTY_NOTICES

Перечень сторонних компонентов, моделей, датасетов и сервисов, используемых
решением, а также смоделированных интеграций. Решение не использует платные
API и подписки в проверяемой версии.

`pip freeze`) и ограничены диапазонами в `requirements.txt`.

## 2. Модели (LLM)

* LLM — **опциональный** компонент. Базовый сценарий полностью
  детерминированный (правила + шаблонные тексты) и работает без модели.
* Если LLM подключена: любая модель **открытых весов** через
  OpenAI-совместимый API (vLLM, Ollama, LM Studio, OpenRouter).
  По умолчанию ожидается `Qwen/Qwen2.5-7B-Instruct`
  (Apache-2.0, https://huggingface.co/Qwen/Qwen2.5-7B-Instruct), ≤120B параметров
  согласно рекомендации кейса.
  Провайдер заменяется переменными `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`
  (см. `.env.example`).
* ML-скоринг и OCR в MVP отсутствуют; место будущей модели обозначено в
  `docs/architecture.md` (модуль `rules.py` / `ai_module.py`).
* Датасеты не используются — все данные синтетические, сгенерированы в
  `database._seed_demo`.

## 3. Внешние сервисы и смоделированные интеграции

| Внешняя система | Как смоделирована | Где в коде |
| --- | --- | --- |
| ЕГРЮЛ / ЕГРИП (статус компании) | Mock-ответ «компания действующая» | `app.py` (карточка «Источники») |
| ФНС (налоговая задолженность) | Mock-ответ «задолженностей нет» | `app.py` |
| БКИ (кредитная история) | Mock-ответ «score 750» либо флаг неполноты `missing_bki` | `database.py`, `rules.py` (R-05) |
| Служба доставки SMS/пуш-кодов | Демо-код показывается в интерфейсе и в ответе API | `database.create_signing_code` |
| ЭП / Госключ / ДБО | Имитация подписания кодом внутри продукта | `database.sign_application` |
| Эквайринг/процессинг (проводки) | Выдача — запись о зачислении на демо-счёт, без проводок | `database.disburse` |

## 5. Бренд и стилизация

Логотип и товарные знаки ПАО «Альфа-Банк» не используются. Палитра
(`#EF3124`) и плотная гротескная типографика — самостоятельная стилизация
(`theme.py`, шрифт Inter Tight загружается с Google Fonts, лицензия SIL OFL).

реализованное решение.
